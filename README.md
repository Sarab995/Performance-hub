Performance Hub

A single-page dashboard for departments to track their work and results in one place. It runs entirely in the browser: no installation, no server, no sign-in.

Live demo: https://sarab995.github.io/performance-hub/

All figures, names and projects in the demo are sample data.

Modules
Tasks / Projects – status of each task across ten stages, from initiation to delivery
Key Performance Indicators – each KPI against its target, with ageing on off-track items
Ad-hoc Requests – one-off work requested by management and other departments
Yearly Plan – the annual calendar, linked to live task status
Strategic Initiatives – progress across six development pillars
Performance Scorecard – a weighted composite score across key measures
Features
Filters, charts and a presentation mode for meetings
Import from and export to Excel; export to JSON
Every title, the company name and the department name can be edited on the page
Edits save automatically in your browser
